# Billing & Staking

Flexia Control Center employs a hybrid billing model that combines traditional SaaS subscriptions with a crypto-native staking mechanism, designed to be compatible with Islamic Finance principles.

## Subscription Tiers

| Tier | Tokens Limit | Staking Requirement (FLX Credit) | Description |
|------|--------------|----------------------------------|-------------|
| **Free** | 10,000 | 0 | Basic access for exploration. |
| **Pro** | 1,000,000 | 1,000 | For professional developers. |
| **Enterprise** | Unlimited | 10,000 | For large-scale organizations. |

## Billing Methods

### 1. Stripe (Fiat/Card)
Users can subscribe using credit cards via Stripe.
- **Pro**: Monthly subscription.
- **Enterprise**: Custom pricing/subscription.

### 2. Crypto Staking (Decentralized)
Users can stake supported crypto assets to earn "FLX Credits". These credits effectively "pay" for the subscription.

**Supported Assets:**
- BTC (Bitcoin)
- ETH (Ethereum)
- BNB (Binance Coin)
- USDT (Tether)

**Islamic Finance Principle:**
The staking mechanism is modeled as a yield/profit-sharing arrangement. The asset remains the user's property. The "payment" is the yield generated by the capital (simulated via FLX Credits).

**Yield Rates (Annual Equivalent):**
- BTC: 5%
- ETH: 4%
- BNB: 6%
- USDT: 3%

**Calculation Logic:**
`FLX Credit = (Asset Value in USD / FLX Price) * Yield Rate`

*Source Logic: `src/services/billing.ts`*

## Quota Management

Usage is tracked via the `user_usage_quotas` table.
- Quotas are reset monthly.
- `checkQuota(userId, tokensRequested)` verifies availability before processing requests.
- Staking status is checked to automatically upgrade tiers if the required FLX Credit threshold is met.
